# Fonts

Stored locally so the site works when index.html is opened by double-clicking, even offline.
All are SIL Open Font License 1.1, downloaded from Google Fonts (Latin subsets).

- Figtree: body text, labels, pill tags
- Archivo (variable, width 62 to 125): the wide folder-divider titles and some ransom letters
- Silkscreen, Pinyon Script, Instrument Serif italic, Rozha One: single letters in the ransom-note title
- Mukta (Devanagari subset): only supplies the ₹ sign, which Figtree doesn't have
- Shrikhand (Jonny Pinhorn): display face for headlines, figures and the cover. SIL Open Font License 1.1.
